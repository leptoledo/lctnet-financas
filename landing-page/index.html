Perguntas Frequentes

Como funciona o app no Android se ele nasceu no iOS?

O Finanças foi clonado e portado utilizando tecnologia PWA (Progressive Web App) de última geração com o mesmo design system do iOS. No Android, você pode instalá-lo com 1 toque através do Chrome e ele funcionará como um aplicativo nativo instalado na gaveta de apps, com ícone e tela cheia.

Os dados são sincronizados entre meu celular e o computador?

Sim! A aplicação possui integração com Supabase PostgreSQL na nuvem com autenticação segura e Row Level Security (RLS). Qualquer lançamento feito no celular aparece instantaneamente na versão Web.

Posso importar os meus dados antigos em planilha CSV?

Com certeza! O Finanças possui motor de importação e exportação em CSV padrão (Data, Nome, Tipo, Categoria, Valor, Notas). Inclusive, o app já vem com dados de exemplo prontos para testar!

Como funciona o período de teste de 7 dias do Pro?

Você pode testar todas as funcionalidades do plano Pro durante 7 dias sem qualquer compromisso. Se não adorar a experiência, basta cancelar sem pagar nada.
